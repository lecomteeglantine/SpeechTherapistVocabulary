Privacy & GDPR · This learning tool is designed according to data-minimisation principles. No account is required, and the site itself does not collect, transmit or store personal data on a remote server.

Saved vocabulary, learning progress, your last learning area, flashcard results, recent practice summaries, progress-check history, 5-minute-session history, recent dictionary searches, Clinical Communication progress, Pronunciation Lab ratings and accessibility preferences are stored only on this device in your browser’s local storage. Pronunciation recordings made with the optional microphone tool are temporary playback recordings: the learning tool does not upload them or save them to local storage. To make the app work offline, the browser may also cache the site’s own static files on this device; this offline cache does not contain personal information. No analytics, advertising trackers or third-party cookies are used by the learning tool. Local data can be removed at any time by clearing the site data in the browser; saved vocabulary can also be deleted from My Vocabulary.

The website is hosted on GitHub Pages. Standard technical connection data may therefore be processed by GitHub as hosting provider under its own privacy policy.
